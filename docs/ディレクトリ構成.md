## レイヤリング規約（実装で厳守）

1. `app/` は **ルーティングと表示のみ**。ビジネスロジックは `lib/` に置く。
2. サーバーコンポーネントは **`lib/queries.ts` を直接呼ぶ**（API を経由しない・SSR 高速化）。
3. **UI から外部 API を直接呼ばない**。取得は必ず `lib/providers/*` の境界越し。
4. `components/` は表示専用。データ取得・副作用を持たせない（props で受ける）。
5. 指標計算・フォーマット・SEO 生成は **純関数**として `lib/` に集約し、ページ間で一貫させる（テスト対象）。
6. 実運用で Prisma/Supabase を入れる場合、DB アクセスは `lib/providers`（or `lib/store`）にのみ閉じ込め、他所から import しない。
7. 巨大な単一コンポーネントを作らない。表示ロジック / データ取得 / ビジネスロジックを分離する。
