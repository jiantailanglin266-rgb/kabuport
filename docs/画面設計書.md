## 状態設計（全画面共通）

- **loading**: スケルトン（Phase 1 は主に静的生成のため最小）。
- **empty**: 破線ボーダーの空状態＋導線（スクリーナー「該当なし」、優待なし等）。
- **error**: エラー境界（Phase 9 で `error.tsx` 拡充）。プロバイダー取得失敗は mock フォールバックで画面を壊さない。

## テーマ定義（デザイントークン）

`src/app/globals.css`。

| トークン | Light | Dark |
|---|---|---|
| `--bg` | `#f5f7fb` | `#070b16` |
| `--card` | `#ffffff` | `#0f1626` |
| `--ink` | `#0b1b3a` | `#e8ecf5` |
| `--muted` | `#5b6472` | `#96a0b5` |
| `--line` | `rgba(11,27,58,.1)` | `rgba(255,255,255,.1)` |
| アクセント | `#2563eb`（brand）/ navy グラデ | 同 |
| 騰落 | up `#e11d48`（赤=上昇, 日本慣習）/ down `#059669`（緑） | 同 |

**騰落は色のみに依存しない**: 色 + 記号(▲▼) + 矢印アイコン + テキストラベル + sr-only。

ダークは `class` 方式（`layout.tsx` の head 同期スクリプトで FOUC 防止）。`prefers-reduced-motion` でアニメ抑制。
